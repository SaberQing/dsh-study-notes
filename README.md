# dsh-study-notes（学习笔记）

> 在 DSH 对话里划词提问，问题进入独立的右侧栏分支，不占用主对话上下文；之后随时点回高亮或索引即可回到当时的问题。

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

> **状态：0.1.0-beta** — 功能可用、已在 DSH desktop `0.2.2-rc.1` 上自测；接口依赖 DSH 扩展位，升级 DSH 后可能需要适配。

## 为什么

用 AI 学习时，遇到不懂的段落通常只有两种选择：

- 直接在**主对话**里追问：问题越积越多，主上下文被稀释、越聊越乱；
- **另开一个对话**：丢失前文，需要重新复述，而且事后很难找回当时的疑问。

学习笔记把这类提问从主对话中分离出来：划词 → 右键「问这个」→ 右侧栏独立分支对话（**不进入主对话上下文**）。文字会被持久高亮，之后点击高亮或从右栏索引即可回到当时的分支，不必重问。

## 主要功能

- **划词分支提问**：独立上下文、流式回答、可停止；可选是否携带主对话记忆。
- **高亮持久化**：按会话隔离；切换会话、刷新、重启 DSH 都不丢。
- **索引与定位**：右栏「学习笔记」索引 + 开始页入口；点问题行可**滚动定位到原对话位置并闪烁**；旧消息自动分页加载；原文失效时提示并复制原文。
- **分支记忆（可选，默认关闭）**：主对话摘要 + 最近 10–15 条原文；懒刷新、本地持久化（加密存储）、摘要可查看/编辑/重建/清空。
- **回注主对话**：把分支问答压成 3–5 条要点，以「预填草稿」或「直接注入」（主对话中出现折叠的 Context injection 行，持久保留）送回主对话。
- **回答渲染**：Markdown、代码块、表格、KaTeX 公式；截断提示 + 继续、卡顿/重试状态条、自动滚动。
- **管理**：批量删除、Markdown / Word(.docx) 导出、单条导出。
- **模型控制**：思考开关、无输出长度上限；支持 DSH 内置模型或**显式选择**自定义 OpenAI 兼容 API。
- **隐私**：API Key 由 Host 端 DPAPI（Windows）或 AES-256-GCM 加密保存，页面只显示前 7 位与后 4 位，不可查看/修改，只能删除后重输。

## 环境要求

- DSH desktop **`0.2.2-rc.1`**（其他版本未验证）
- 无需额外 Node 依赖；使用 Windows 时获得最强的 API Key 保护（DPAPI）

## 安装

本插件以本地 bundle 形式安装。先把本仓库放到一个固定目录，然后二选一：

**方式 A：插件管理器（推荐）**

```text
plugin_manager install_bundle  <插件目录绝对路径>
```

**方式 B：手动挂载**

1. 在 DSH profile 的 `package.json` 中把插件加入依赖（路径按实际位置修改）：

```json
{
  "dependencies": {
    "@local/dsh-study-notes": "link:<插件目录绝对路径>"
  },
  "dsh": {
    "profile": {
      "bundles": ["...", "@local/dsh-study-notes"]
    }
  }
}
```

2. **完全退出并重启 DSH**（Host 代码只在启动时加载，刷新页面不够）。

详细步骤、卸载与常见问题见 [docs/public/installation.md](docs/public/installation.md)。

## 快速上手

1. 在对话中划选一段文字 → 右键 → 「问这个」；
2. 右侧栏打开「学习笔记」并显示该分支，直接提问；
3. 之后点击该处**高亮**，或右栏索引里的条目，即可回到这个分支；
4. 列表行点击 = 定位到原对话并闪烁；行上「打开」= 进入分支详情；
5. 全局设置在 **设置 → 学习笔记**（模型来源、思考、记忆、回注方式、API Key）。

## 设置项（设置 → 学习笔记）

| 设置 | 默认 | 说明 |
|---|---|---|
| 模型来源 | DSH 内置模型 | 内置 / 自定义 OpenAI 兼容 API（显式选择，不互相回退） |
| 思考 | 开 | 内置模型走 DSH 能力；自定义 API 可选参数格式 |
| 记忆 | 关 | 开启后分支提问携带主对话摘要 + 最近 N 条原文 |
| 主对话窗口 | 10 | 10–15 条 |
| 回注方式 | 预填草稿 | 预填草稿（不自动发送）/ 直接注入 |

## 隐私与安全

- 会话、笔记、分支问答、摘要均保存在**本机**（浏览器 localStorage + `~/.dsh/study-notes/`）；
- **API Key**：Host 端加密存储，前端仅显示脱敏 preview；请求体不含 Key；
- 除模型请求外，不向任何第三方发送数据；
- 完整说明见 [docs/public/privacy.md](docs/public/privacy.md)。

## 已知限制

- 依赖 DSH 的扩展位与部分内部接口（右栏 tab、`settings.section`、`agent.inject`/`session.append`、会话消息派生、对话 DOM 的 `data-*` 约定），**DSH 升级可能导致功能失效**；
- 「直接注入」仅在主对话空闲时持久落盘；主对话生成中会排队并提示“尚未落盘”；
- 定位到对话依赖对话 DOM 约定，旧消息需要分页加载；
- 笔记/分支问答保存在浏览器 localStorage，**未加密**（本地同用户可读；如需更强保护请使用系统账户隔离或清空数据）；
- 右栏宽度 < 768px 时按 DSH 设计变为全屏抽屉；
- 界面目前为中文；记忆摘要与回注摘要使用 DSH 内置模型。

详见 [docs/public/known-limitations.md](docs/public/known-limitations.md)。

## 开发与结构

```
package.json      DSH bundle / client 清单
cordis.patch.yml  插件挂载
index.js          Host：LLM 路由、摘要/记忆/回注/密钥路由
client.js         Client：右栏 tab、高亮、索引、定位、设置分区、导出
locale/           本地化文本
icon.svg          图标
```

- 无构建步骤：`client.js` 为手写 `window.__ModuleLoader__` bundle；
- Host 改动需要完全重启 DSH，客户端改动刷新页面即可。
