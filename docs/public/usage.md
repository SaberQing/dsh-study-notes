# 使用说明

## 划词提问

1. 在对话中划选一段文字；
2. 右键 → 「问这个」；
3. 右侧栏打开「学习笔记」，显示选中的引用与分支对话；
4. 输入问题（Enter 发送，Shift+Enter 换行），回答流式输出，可点「停止」。

分支对话**不会进入主对话上下文**。

## 高亮与回访

- 划词后会留下持久高亮（下划线 + 淡蓝背景）；
- 点击高亮 → 打开该分支；
- 右栏索引也可进入；高亮按会话隔离。

## 索引、定位与打开

- 标签条「+」→ 开始页 → 「学习笔记」卡片 → 打开索引；
- **点列表行 = 定位**：主对话滚动到原文位置并闪烁；
- 行上「打开」= 进入分支详情；
- 详情页「定位」= 同样定位；
- 很旧的笔记会自动加载更早的对话后定位；找不到原文会提示并复制原文。

## 批量与导出

- 勾选条目（不触发定位/打开），可全选；
- 「删除选中」需确认；
- 「导出 Markdown / 导出 Word」：有勾选导出选中，否则导出当前会话全部；
- 详情页「导出」只导出当前条。

## 分支记忆（可选）

在 **设置 → 学习笔记 → 记忆** 开启：

- 提问时携带主对话摘要 + 最近 N 条主对话原文（N 默认 10，可选 10–15）；
- 回答后按需在后台刷新摘要（主对话推进 ≥5 条才刷新，不阻塞提问）；
- 右栏「记忆」按钮可查看/编辑当前会话摘要：保存、重新生成、清空；
- 摘要与手改内容重启 DSH 后仍保留；摘要存于本机加密文件。

## 回注主对话

详情页「回注主对话」：

1. 自动生成 3–5 条要点（疑问/已澄清/仍不确定），可编辑；
2. 「预填草稿」：内容放入主输入框，不自动发送，你确认后自行发送；
3. 「直接注入」：写入主对话，显示为折叠的 Context injection 行；主对话空闲时持久保存，重启后仍在；生成中则排队并提示尚未落盘；
4. 「再次回注」复用上次内容；会话不可写时自动回退为预填。

## 设置（设置 → 学习笔记）

- **模型来源**：DSH 内置模型（默认）/ 使用自定义 API（显式选择，不互相回退）；
- **思考**：开关 + 自定义 API 的思考参数格式；
- **记忆**：开关 + 主对话窗口条数；
- **回注方式**：预填草稿（默认）/ 直接注入；
- **API Key**：仅自定义模式；保存后只显示前 7 位与后 4 位，不可查看/修改，只能删除重输。

## 回答显示

- Markdown（标题/列表/表格/代码块）、KaTeX 公式；
- 达到输出上限时显示 ⚠ 截断提示并提供「继续」；
- 状态条显示生成中、网络重试（5 次 × 5 秒）、15 秒无响应卡顿提示；
- 自动滚动：发送/切换笔记贴底，向上翻不抢滚动。
